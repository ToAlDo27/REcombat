# Third-party code

The Vortex room view follows the official Owlbear bridge from
[tldrpg/lss-vtt-sdk](https://github.com/tldrpg/lss-vtt-sdk/tree/master/bridges/vortex):
the shared room binding, Vortex iframe URLs, iframe sandbox, and room-selection messages.
It is adapted for REcombat's token window with source validation and explicit room controls.

REcombat also depends on the official `@longstoryshort/vtt-sdk`. Distribution includes its license
in `THIRD_PARTY_LICENSES.txt`, along with the other runtime dependencies.
