# REcombat · LSS Bridge 0.1.0

Прототип для Google Chrome и Microsoft Edge. Передаёт готовый результат инициативы из обычной вкладки Long Story Short в одну выбранную комнату Owlbear с REcombat 1.3.0.

## Установка

1. Распакуйте ZIP в постоянную папку. Если сборка создана локально, готовая папка — browser-bridge/build.
2. В Chrome откройте chrome://extensions, в Edge — edge://extensions.
3. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.
4. Закрепите REcombat · LSS Bridge на панели браузера.
5. Обновите вкладки Owlbear и LSS. Откройте сцену с REcombat 1.3.0.
6. Нажмите значок моста, выберите комнату и нажмите «Подключить».
7. В данных нужного токена REcombat сохраните ссылку на персонажа LSS и включите «Принимать инициативу из LSS». Для отображения в списке боя токен должен быть добавлен в REcombat.
8. Нажмите инициативу в обычном листе LSS. Число должно появиться у связанного токена; в меню моста будет подтверждение сохранения.

Обе вкладки должны находиться в одном профиле браузера. Панель REcombat может быть закрыта. Второй участник, сервер и Vortex для этого пути не нужны.

## Что именно передаётся

Только новая инициатива: ID персонажа из адреса страницы, целочисленный итог, время и идентификатор доставки. ID определяет токен; одинаковые имена не используются для поиска.

Атаки, другие проверки, старые броски, закрытые вкладки, скрытые броски и неизвестный формат события не передаются. Доставки в закрытую комнату не накапливаются. При смене сцены или ошибке сохранения проверьте статус моста и выполните новый бросок.

ХП, КЗ, бонусы и автоматическое добавление нового участника в очередь этим прототипом не изменяются.

## Совместимость и доступ

Используется внутренний CustomEvent lss:roll текущего листа, record.version = 1, meta.kind/statKey = initiative. Это не публичный API LSS: обновление сайта может потребовать обновить адаптер. Числа с экрана не считываются, бросок повторно не выполняется.

Расширение работает только на страницах LSS, Owlbear и REcombat. Оно не читает пароли, куки или токены авторизации, не отправляет события на сторонний сервер и не изменяет ограничения встраивания LSS.

Выбор комнаты хранится на время сеанса браузера. После перезапуска выберите её снова. При обновлении расширения обновите обе вкладки.

## Проверка сборки

Автоматические испытания загружают настоящее MV3-расширение в отдельный Chromium и передают событие между двумя вкладками с контролируемым листом и реальным кодом REcombat; сеть Owlbear заменена тестовым транспортом. Эти испытания не заменяют проверку под вашим аккаунтом LSS.
