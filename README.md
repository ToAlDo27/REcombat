# REcombat

Самостоятельное расширение для **Owlbear Rodeo** от [ToAlDo27](https://github.com/ToAlDo27): общая инициатива, ХП/КЗ на токенах, подсветка текущего хода и звук удара меча.

- [Открыть страницу расширения](https://toaldo27.github.io/REcombat/)
- **Ссылка установки:** https://toaldo27.github.io/REcombat/manifest.json
- [Исходный код](https://github.com/ToAlDo27/REcombat)

## Установка

В комнате Owlbear Rodeo откройте **Extras → Extensions → Add Extension**, вставьте ссылку `manifest.json`, добавьте REcombat и откройте сцену. Расширение работает отдельно от REtracks; можно установить оба.

## Использование

### Инициатива из обычной вкладки LSS — прототип

Для Chrome/Edge подготовлен [REcombat · LSS Bridge 0.1.0](https://toaldo27.github.io/REcombat/recombat-lss-bridge-0.1.0.zip). Это отдельное браузерное расширение: [установка и ограничения](browser-bridge/README.md).

После установки обновите обе вкладки, выберите комнату через значок моста и нажмите «Подключить». На токене должны быть сохранены ID/ссылка персонажа и разрешён приём инициативы из LSS. Бросок выполняется в обычной вкладке longstoryshort.app; REcombat принимает его в фоне и сохраняет результат по ID. Второй участник не нужен. Требуется REcombat 1.3.0.

Передаются только новые броски инициативы. Это экспериментальный адаптер внутреннего события LSS, а не официальный публичный API. ХП/КЗ этим мостом не синхронизируются.

### Работа с токенами

1. Нажмите **ПКМ на токене → «Данные токена · REcombat»**. Откроется отдельное окно токена, даже если основная панель REcombat закрыта. Также работает **«Выбрать из сцены» → «Настроить»** в панели. В карточке задайте имя, текущие/максимальные ХП, КЗ, бонус инициативы, сторону и преимущество/помеху. Карточку можно сохранить **до добавления в бой**; ХП/КЗ уже появятся на карте.
2. Нажмите **«Сохранить и добавить в бой»**, выбрав режим инициативы: взять число из карточки, бросить сразу или оставить пустое поле. Общий режим задаётся ведущим в **«Настройки боя → При добавлении токена»**. Пункт **ПКМ → «Добавить в REcombat»** добавляет один или несколько выделенных токенов. Кнопка **«Выделенные токены»** в панели делает то же с сохранёнными параметрами. Повторное добавление не сбрасывает бой.
3. В списке боя поля сохраняются по Enter или при выходе из поля. В ХП можно ввести -4 для урона, +5 для лечения или число для установки значения. ХП ограничены от нуля до максимума. Изменения отражаются в карточке токена; удаление из очереди сохраняет профиль.
4. Бросьте инициативу каждому или нажмите **«Бросить всем»**. Общие кость, направление сортировки и режим броска задаёт ведущий. Индивидуальный режим токена имеет приоритет над режимом комнаты. При равенстве учитываются бонус, имя и стабильный ID.
5. Нажмите **«Начать бой»**, затем **«Следующий ход»**. Завершение боя сохраняет участников и показатели.
6. Каждый слушатель нажимает **«Включить звук»**, затем **«Разрешить и проверить звук»** в появившемся звуковом виджете. Прозвучит пробный удар, виджет свернётся до небольшой полоски. Оставьте её открытой: она озвучивает ходы даже при закрытой панели боя. После перезагрузки разрешите звук снова. Громкость и выключение звука личные; крестик виджета выключает звук.

По умолчанию все игроки могут редактировать общий список одновременно. Ведущий может разрешить только своих участников и отдельно разрешить переключение ходов игрокам. Сохранение карточек вне боя в режиме «Только свои» доступно создателю токена и ведущему. Показатели и подсветка рисуются фоновым процессом.

Скрытие показателей NPC — настройка отображения. Метаданные сцены доступны клиентам комнаты. Невидимые токены не получают локальных меток у игроков.

## Long Story Short

В **карточке токена → Персонаж LSS** вставьте ссылку вида https://longstoryshort.app/characters/digital/ID/ или сам ID. Допускаются также ссылки конструктора и iframe; они преобразуются в обычную ссылку на лист. Включите **«Принимать инициативу из LSS»**. Связь идёт по ID, а не по имени.

### Официальные листы для Owlbear

Добавьте нужные манифесты отдельно через Extensions → Add Extension:

- Лист D&D: https://bridge.longstoryshort.app/dnd/obr/manifest.json
- Vortex: https://bridge.longstoryshort.app/vortex/obr/manifest.json

Игрок открывает свой официальный лист под своим аккаунтом и делает бросок **«Инициатива»** или **«Initiative»**. REcombat принимает один целый результат, записывает его на связанный токен и в очередь боя. Атаки, проверки других навыков и пары результатов вроде «18 | 7» пропускаются: итог пары выберите вручную.

**Ограничения официального моста:** он отправляет только броски по каналу rodeo.lss/sheet-events другим клиентам комнаты. Собственное расширение на том же клиенте эту рассылку не получает. Поэтому включите REcombat у ведущего и игроков: другой клиент получает бросок и возвращает его через внутреннюю рассылку всем, а один выбранный обработчик (ведущий в приоритете) записывает инициативу. Так принимается и бросок самого ведущего. Если в комнате единственный клиент с REcombat, используйте ручной ввод или встроенный лист. Панель боя может быть закрыта.

ХП, КЗ, бонус инициативы и данные карточек Vortex официальный мост другим расширениям не отправляет. Их вводят в REcombat вручную. Дополнительные уведомления о бросках REcombat не создаёт, чтобы не дублировать официальный лист/Vortex.

### Встроенный лист

Пункт **ПКМ → «Открыть лист LSS»** открывает вкладку листа в отдельном окне токена. Там же есть ссылка **«Открыть этого персонажа на LSS»** для просмотра в обычной вкладке. В панели боя у привязанного участника есть кнопка **«Встроенный лист»**. Используется официальный SDK 0.9.0 с проверкой origin и окна-источника. **Адрес развёрнутого REcombat должен быть разрешён на стороне LSS**; без этого используйте официальные расширения выше. Разрешение домена самостоятельно REcombat выдать не может.

Из открытого встроенного листа принимаются броски инициативы и экспериментальные события dnd:health (текущие/максимальные ХП). Временные ХП, КЗ и бонус не импортируются. Правки REcombat обратно в лист не отправляются. Связь с ХП работает, пока встроенный лист открыт; закрытие листа оставляет последние значения на токене.

Первичные источники: [интеграция Owlbear](https://longstoryshort.app/doc/integration/owlbear/), [встраивание](https://longstoryshort.app/doc/developers/embedding/), [справочник SDK](https://longstoryshort.app/doc/developers/embedding/sdk-guide/), [код официального моста](https://github.com/tldrpg/lss-vtt-sdk/blob/master/bridges/dnd/src/main.ts).

## Vortex как основа общего просмотра

В окне токена откройте вкладку **«Vortex»**. Подключение комнаты основано на [официальном Owlbear-мосте Long Story Short](https://github.com/tldrpg/lss-vtt-sdk/tree/master/bridges/vortex), MIT © 2026 tldrpg; атрибуция и лицензия включены в сборку.

Если комната уже выбрана в официальном расширении Vortex, REcombat автоматически откроет её. Если комната ещё не выбрана, ведущий выбирает её в официальной панели внутри окна. Это общая привязка для всей комнаты Owlbear, поэтому изменить её может только ведущий. Открытие окна само по себе ничего не перепривязывает. Недоступная комната не удаляется автоматически: ведущий может явно нажать **«Выбрать другую комнату Vortex»**.

Здесь показывается официальный интерфейс Vortex: карточки группы, показатели и общий лог. Доступ к персонажам определяет LSS; сохранение чужого ID на токене не выдаёт прав на лист. Если встраивание недоступно, используйте ссылку **«Открыть Vortex в отдельной вкладке»**. Подключение комнат и самих персонажей происходит под аккаунтом пользователя в LSS.

**Граница синхронизации:** официальный мост Vortex не отдаёт HP/КЗ токенам через публичный протокол. Поэтому общую группу можно смотреть и вести в Vortex, а данные токена хранятся в REcombat; инициативные броски приходят из связанного листа LSS. ХП из своего открытого встроенного листа принимает SDK, как описано выше. Автоматической полной двусторонней синхронизации Vortex ↔ токен нет.

REcombat не создаёт второй всплывающий журнал Vortex и не меняет настройки уведомлений официального моста.

## Сохранение и одновременный ввод

Участники, настройки, результаты бросков, раунд и текущий ход хранятся в **метаданных текущей сцены Owlbear Rodeo**. При открытии расширение только читает существующие данные; значения по умолчанию не записываются поверх боя. Перезагрузка страницы, закрытие панели и повторный вход не создают новый список. Другие сцены имеют собственный бой.

Карточки хранятся также в item.metadata под ключом com.toaldo27.recombat/token и переносятся вместе с токеном. Источник истины внутри сцены — журнал операций; метаданные токена служат восстанавливаемой копией. При отказе обновления токена показана ошибка, а подтверждённое сохранение сцены остаётся доступно.

Каждое изменение записывается под отдельным уникальным ключом журнала. Клиенты не перезаписывают весь список: одновременные регистрации разных участников, изменения разных полей и относительный урон/лечение сохраняются независимо. Повторная регистрация одного токена не сбрасывает его показатели. Журнал воспроизводится в едином детерминированном порядке (часы Lamport, ID автора, ID операции). Для одновременных изменений одного абсолютного поля применяется последнее изменение в этом порядке. Два переключения, основанные на одном текущем ходе, сводятся к одному переходу.

Индикация **«Сохранено»** означает, что запись подтверждена API сцены. При ошибке записи показывается уведомление, неподтверждённое изменение откатывается. Для записи нужен доступ к комнате и работающая связь с Owlbear Rodeo. Это не автономный режим.

Журнал не очищается автоматически, чтобы не удалить конкурентные изменения. Для очень длинных кампаний используйте отдельные сцены для сражений: объём метаданных увеличивается с количеством изменений. Удаление сцены или ручное удаление метаданных удаляет сохранение. Локальная громкость не переносится между устройствами.

## CLASH

Идея набора функций вдохновлена [CLASH](https://extensions.owlbear.rodeo/clash) от Battle-System. У его автора найден публичный [clash-export](https://github.com/ManuelLovell/clash-export), но это экспортёр коллекций старого CLASH, а не исходники полного актуального трекера. Публичный репозиторий полного CLASH при проверке не найден. **REcombat написан независимо; код и ресурсы CLASH не скопированы.**

## Разработка

Node.js 22:

```sh
npm ci
npm run dev
npm run check:release
npm test
npm run lint
npm run package
```

Для публикации в подпапке задайте `VITE_BASE_PATH=/REcombat/`. Сборка включает index.html, background.html, audio.html, token.html, манифест и лицензии. Ссылка **«Исходный код»** ведёт на репозиторий; архив исходников на сайте не создаётся.

`npm run test:browser` запускает Playwright с Chrome. Тестовая конфигурация использует подмену транспорта SDK, не включаемую в production. Проверяются три клиента с общими метаданными, одновременное добавление, урон, независимые правки, повторное открытие, ходы, интерфейс 400 px и локальные метки. Модульные тесты проверяют воспроизведение журнала, гонки чтения/записи, смену сцены, отказ записи, права и звук. Проверки с подменой транспорта не заменяют проверку в настоящей игровой комнате Owlbear Rodeo.

GitHub Actions запускает тесты, линтер и сборку, затем публикует сайт через GitHub Pages.
